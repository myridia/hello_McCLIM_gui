mcclim

The smallest useful McCLIM application: a window that says Hello, world! with a Quit button. Pass -nw and it prints the greeting to the terminal instead — handy for scripts and smoke tests.

Download latest View source README

What it does

One McCLIM frame

define-application-frame with an application pane for the message and a push button that calls frame-exit. That's the whole GUI.

No-window mode

-nw, --nw or --no-window skips McCLIM and prints Hello, world! to stdout. No display required.

Self-contained executable

sb-ext:save-lisp-and-die bakes McCLIM and the Lisp runtime into one ~22 MB binary. No SBCL, Quicklisp or lib/ tree needed on the target machine. DejaVuSans.ttf ships beside it, so no system fonts are needed either.

Guided setup

Task 1 checks for SBCL and a downloader, bootstraps Quicklisp into ~/quicklisp, and loads McCLIM through ql:quickload.

Cross-platform installer

The setup script knows apt, dnf and pacman on Linux, Homebrew on macOS, and Chocolatey, Scoop or winget under a POSIX shell on Windows.

Simple task runner

./ask.sh offers Setup, Build and Run. Each task is a small script in ask.d/, so it's easy to see what happens.

Tiny codebase

main.lisp is about 40 lines: load Quicklisp, quickload McCLIM, define the frame, parse the command line, run either mode.

CI built in

A single Build Control workflow drives the Linux build: install SBCL/McCLIM, compile, smoke-test -nw, and upload the binary.

Run it

# start the McCLIM window
sbcl --script main.lisp

# or use the task runner
./ask.sh

# built executable, no window
./dist/mcclim/mcclim -nw

Without a flag, the executable opens the window. With a no-window flag it prints to the terminal and exits.

Quick start

git clone https://github.com/veto8/mcclim.git
cd mcclim
./ask.sh          # task 1: install SBCL + Quicklisp + McCLIM
                  # task 2: build bin/ and dist/mcclim/
                  # task 3: run main.lisp
